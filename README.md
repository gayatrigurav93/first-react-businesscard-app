# React BusinessCard App 🪪

A simple React mini project that displays a digital business card using reusable components and props.  
This project was built to practice React fundamentals such as **components, props, and JSX**.

---

## 🚀 Features
- Displays info like name, role, email, and phone number.
- Built with **React functional components**.
- Props used to pass dynamic data into the card.
- Responsive and beginner‑friendly structure.
